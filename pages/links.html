Your site must pass all of the following checks before the handshake completes. Non-compliance causes an RST packet.
  • [TLS_1.3] Transport Layer: TLS 1.3 minimum. TLS 1.2 with deprecated cipher suites fails the handshake. SSLv3 triggers an immediate blacklist with reason ANCIENT_CRYPTO. Run nmap --script ssl-enum-ciphers on yourself before applying.
  • [SIGNAL_INTEGRITY] Content must be original technical work: vulnerability research, tool builds, CTF write-ups, or security engineering. Reposts without analysis, SEO keyword spam, and "Top 10 Tools You Must Know" listicles fail the integrity check with LOW_SNR.
  • [LIVENESS] Node must respond within 5 seconds. Cold nodes (last post >12 months, or HTTP 5xx on root URL) are classified ZOMBIE and rotated to offline status automatically. A zombie that returns to life gets re-promoted without ceremony.
  • [CLEAN_PAYLOAD] Your site must contain zero malicious payloads, drive-by exploits, cryptominers, hidden iframes, or affiliate redirect chains. We run periodic passive scans. Detection triggers immediate removal, zero appeals — this is a blog, not a bug bounty.
  • [NO_DARK_PATTERN] No deceptive UI, fake download buttons, pop-under ads, or browser notification spam. If your monetization strategy degrades user experience below a C-grade in Lighthouse, you're not a peer, you're ad inventory.
  • [RECIPROCITY] You must link back to this node first. We verify. One-way links are not friendship — they're just bookmarks. Put us anywhere visible: sidebar, footer, links page. An <a> buried in a comment doesn't count.
ACK
